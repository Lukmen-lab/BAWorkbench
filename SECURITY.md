# Security policy

## Supported version

The latest tagged release is supported. Version 0.1 is an alpha research release.

## Reporting a vulnerability

Please do not disclose a security vulnerability in a public issue. Use GitHub's private **Security advisories** feature for this repository. Include the affected version, reproduction steps, potential impact, and any proposed mitigation.

For ordinary defects in chemistry generation or scientific interpretation, open a normal GitHub issue and avoid including confidential or personally identifiable data.
