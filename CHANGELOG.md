# Changelog

All notable changes are documented here. The project follows semantic versioning.

## [0.1.0] - 2026-10-05

Initial public alpha release.

- Added seven bile-acid cores and mapped reaction-site validation.
- Added covalent candidate generation, exact-mass/adduct metadata, QC tables, and docking exports.
- Included unmodified bile acids as reference candidates.
- Added explicit arginine attachment-site models and removed default cystine duplication.
- Added the Streamlit review/curation Workbench and graceful shutdown control.
- Added cross-platform setup, tests, CI, citation metadata, and public documentation.
